# Повна українська локалізація веб-інтерфейсів Stoneforge

## Мета

Перекласти українською весь видимий інтерфейс `control-center-web`, `quarry-web`, `smithy-web`, `smithy-next` і спільного пакета `@stoneforge/ui`.

## Межі

- Перекласти заголовки, навігацію, кнопки, labels, placeholders, accessibility-атрибути, empty/loading/error states, toast-повідомлення та статуси.
- Використовувати `uk-UA` для дат, часу й чисел.
- Не змінювати API, маршрути, типи, ідентифікатори, назви пакетів, файлові шляхи, кодові блоки та користувацькі дані.
- `apps/smithy-next` локалізується як окремий mock-прототип; його mock-дані, назви файлів і код редактора не перекладаються.

## Порядок

1. Перекласти спільні компоненти та константи `packages/ui`.
2. Перекласти основні навігаційні й route-компоненти `quarry-web`.
3. Перекласти layout, навігацію та route-компоненти `smithy-web`.
4. Перевірити `control-center-web` і зберегти наявну українську локалізацію.
5. Підключити локалізацію до `smithy-next`.
6. Запустити typecheck/build для всіх web apps, `git diff --check` і контрольний пошук англомовного UI.

## Критерії готовності

- У production UI не залишаються англомовні labels, buttons, headings, placeholders або статусні повідомлення.
- Відсутні помилки TypeScript і production build.
- Не змінено поведінку, маршрутизацію чи API-контракти.
