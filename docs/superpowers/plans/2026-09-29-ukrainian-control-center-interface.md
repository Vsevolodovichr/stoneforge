# Українська локалізація інтерфейсу Control Center — план реалізації

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task.

**Мета:** Перекласти весь видимий інтерфейс `apps/control-center-web` українською мовою.

**Архітектура:** Зберігаємо наявну структуру React-компонентів і замінюємо лише UI-копірайт, accessibility-атрибути, fallback-повідомлення та локаль форматування дат. Окремий i18n-шар не додається, оскільки застосунок має одну мову й не потребує перемикання локалі.

**Стек:** React 19, TypeScript, Vite, `@stoneforge/ui`.

**Специфікація:** Запит користувача: «повний переклад на українську мову» → уточнено: лише інтерфейс.

## Глобальні обмеження

- Змінювати лише інтерфейс `control-center-web` та безпосередньо використані ним shared UI-файли.
- Не змінювати API, стан, маршрутизацію чи поведінку кнопок.
- Не перекладати назви продуктів `Stoneforge`, `Quarry`, `Smithy`, команду `sf` і шляхи файлової системи.
- Використовувати українську локаль `uk-UA` для відображення дат.

## Фокус перевірки

- Порожній список і пошук мають показувати українські повідомлення.
- Модальне вікно додавання проєкту має мати українські labels, placeholders, validation та action-кнопки.
- Accessibility-атрибути й `title` не повинні залишатися англійською.
- Fallback-помилки валідації не повинні повертати англійський текст.
- TypeScript і production build мають проходити після замін.
